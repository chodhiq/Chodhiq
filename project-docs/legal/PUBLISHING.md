# ChodhiQ public legal pages

The official public site is `https://chodhiq.co.uk/` and is hosted through Cloudflare. Static beta information page sources (`privacy.html`, `terms.html`, and `delete-account.html`) are in `site-static/`; verify their deployment at `chodhiq.co.uk` before relying on them. The business dashboard separately hosts `/terms`, `/privacy`, `/delete-account`, `/moderation-policy`, and `/retention-policy`; those routes return 404 until an approved generated bundle is prepared. The customer beta build separately refuses missing or placeholder HTTPS legal URLs.

Before enabling the separate business-dashboard legal routes or preparing a wider launch, decide and verify the legally appropriate operator/controller disclosures, any required representative details, applicable law, liability wording, and record-specific retention. ChodhiQ operates virtually from India and has no physical address; do not insert an invented address. The published beta pages state the email contacts, 18+ audience, effective date, named beta services, Mumbai Supabase region, 14-day deletion commitment, and no routine Supabase database backups. Review these statements against production data flows, retention/deletion implementation, suppliers/transfers, and Google Play Data safety answers. Do not put invented values into these documents.

For the separate business-dashboard publication, complete the remaining legal review items, then create `PUBLICATION.json` from `PUBLICATION.example.json` with the approved HTTPS origin, monitored privacy email, approving names, and approval date. Run `npm run legal:prepare` from the workspace root. It refuses missing approval fields, invalid URL/email, and unresolved placeholders, then writes the approved content to `business-dashboard/lib/legal-publication.generated.json`.

Review the generated pages and run `npm run verify` in `business-dashboard`. Deploy that separate site, then check that all five routes return 200 without sign-in on its actual public origin and that the deletion email is monitored and can process a request. Keep the already published static beta URLs and Play Console links aligned. Run `npm run verify:release` and build a new beta AAB when preparing a new release.

The public static pages are versioned in `site-static/`. The Privacy page now discloses Resend SMTP for Supabase authentication email, including Resend's United States storage, Ireland sending region, and Free-plan retention. Any content change requires reviewing the change, publishing the updated static site, and confirming that app/store links still resolve. The separate dashboard pages continue to require their own approval workflow.
