# Expo button and interaction registry

Scope: customer Expo app at the workspace root (`App.js`, `components/`, `screens/`,
`src/components/`, `src/navigation/`, and `src/screens/`). The provider and administration web
apps and the nested historical `Chodhiq/` copy are excluded.

Controls repeated in lists or grids are grouped. A component's shared control is listed with its
consumer so the screen-level behavior is visible. “OK” means the handler is attached and the
interaction is wired for the behavior stated; unresolved limitations are identified explicitly.
The UI gallery entries are deliberately visual-only previews.

## Checks with no confirmed defect

- Every registered `navigate`/`replace` target checked against the root navigator; no unresolved route targets found.
- `ResetPasswordScreen.js` does not exist. This is a module consolidation, not a stale import: `ResetPasswordScreen` is exported by `src/screens/AccountScreens.js` and imported/registered by `src/navigation/RootNavigator.js`.
- Apple sign-in is rendered only when `Platform.OS === 'ios'`.
- Busy/loading states for password, email confirmation, booking, post publishing, export, delete, claim submission and media selection have reset paths (`finally` or explicit completion).
- Automated interactions: `npm run test:buttons` runs the navigation, authentication, home/discovery/map, community, business/account, listing/marketplace/privacy, settings, and no-dead-button suites.
- Verification: 8 button suites / 65 tests pass and `npm run typecheck` passes. `npm run test:ci` still reports two existing failures: [showcase-readiness.test.mjs](../tests/showcase-readiness.test.mjs) asserts the former campaign-list viewability implementation, and [production-guards.test.js](../tests/unit/production-guards.test.js) expects a different Expo owner from the current `app.config.js`.
- Shared `MotionTouchable`, `PressableScale` and `GlowButton` apply accessibility defaults and minimum 44×44 targets; `npm run accessibility:check` passes. No confirmed small target or missing accessible name was found.
- No product control has a missing/undefined handler, empty callback, or TODO/console-only `onPress`. The unhandled controls in `DevUIGallery.tsx` are visual-only specimens.
